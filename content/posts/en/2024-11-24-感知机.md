### Perceptron Principles and Implementation

The perceptron is a foundational concept in machine learning and the cornerstone of neural networks. This article explores the principles and implementation of perceptrons through single-output perceptrons, multi-output perceptrons, the chain rule, and the backpropagation algorithm.

---

#### Single-Output Perceptron

The single-output perceptron is the simplest neural network. Its core idea is to use a linear function $ y = XW + b $ to map the input to the output.

##### Mathematical Formulation

- Activation function:
  $ y = \sigma(\mathbf{X} \cdot \mathbf{W} + b) $
  where $ \sigma $ is an activation function (typically the sigmoid).
- Loss function (squared error):
  $ E = \frac{1}{2}(O - t)^2 $

##### Gradient Calculation

Using gradient descent to optimize perceptron weights, we have:
$ \frac{\partial E}{\partial w_j} = (O - t) \cdot O \cdot (1 - O) \cdot x_j $

##### Python Example

```python
import numpy as np

# Activation function
def sigmoid(x):
    return 1 / (1 + np.exp(-x))

# Forward pass
def forward(X, W, b):
    return sigmoid(np.dot(X, W) + b)

# Loss function
def loss(O, T):
    return 0.5 * np.sum((O - T) ** 2)

# Gradient update
def update_weights(X, W, b, O, T, lr=0.1):
    delta = (O - T) * O * (1 - O)
    dW = np.dot(X.T, delta)
    db = np.sum(delta)
    W -= lr * dW
    b -= lr * db
    return W, b
````

#### Multi-Output Perceptron

The multi-output perceptron extends the single-output version to allow multiple output nodes, suitable for multi-class classification tasks.

##### Mathematical Formulation

* Multi-output formula:
  $ y_k = \sigma(\mathbf{X} \cdot \mathbf{W_k} + b_k) $

* Total error:
  $ E = \frac{1}{2} \sum_k (O_k - t_k)^2 $

##### Gradient Calculation

$ \frac{\partial E}{\partial w_{jk}} = (O_k - t_k) \cdot O_k \cdot (1 - O_k) \cdot x_j $

#### Chain Rule

The chain rule is the core tool used to compute gradients in complex neural networks. It propagates the error step by step through each layer.

##### Chain Rule Formula

$ \frac{\partial y}{\partial x} = \frac{\partial y}{\partial u} \cdot \frac{\partial u}{\partial x} $

In neural networks:

$ \frac{\partial E}{\partial w_j} = \frac{\partial E}{\partial O_k} \cdot \frac{\partial O_k}{\partial x} \cdot \frac{\partial x}{\partial w_j} $

##### Python Example

```python
def chain_rule_grad(X, W, b, T, lr=0.1):
    O = forward(X, W, b)
    delta = (O - T) * O * (1 - O)
    dW = np.dot(X.T, delta)
    db = np.sum(delta, axis=0)
    W -= lr * dW
    b -= lr * db
    return W, b
```

#### Backpropagation Algorithm

Backpropagation applies the chain rule across all layers of a neural network.

##### Formula Derivation

* Output layer:
  $ \delta_k = (O_k - t_k) \cdot O_k \cdot (1 - O_k) $

* Hidden layer:
  $ \delta_j = (\sum_k \delta_k \cdot w_{jk}) \cdot O_j \cdot (1 - O_j) $
