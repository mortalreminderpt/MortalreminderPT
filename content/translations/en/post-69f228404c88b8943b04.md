## Purpose

`useMemo` is a Hook provided by React that caches the result of a computation between re-renders of a component. It accepts a "create function" and a dependency array; when the dependencies change, the value is recomputed; otherwise, the cached value is returned. It is mainly used to optimize performance and avoid performing time-consuming computations on every render.

**Example:**

```jsx
import { useMemo } from 'react';

function MyComponent({ items }) {
  const processedItems = useMemo(() => {
    return items.map(item => /* ...复杂计算... */);
  }, [items]);
  
  return /* 使用 processedItems 渲染组件 */;
}
```

In this example, `processedItems` is only recomputed when `items` changes; otherwise, the cached result is used.

## Notes

### 1. Use only for performance optimization

`useMemo` should be used only for performance optimization. If `useMemo` is not used, the code should still work correctly. Do not rely on `useMemo` to ensure the correctness of a component.

### 2. The dependency array must be accurate

The second argument of `useMemo` is the dependency array, which must contain all external variables used in the computation function. Omitting dependencies or including them incorrectly may cause the cache to become invalid or produce incorrect results.

**Example:**

```jsx
const memoizedValue = useMemo(() => computeExpensiveValue(a, b), [a, b]);
```

Make sure both `a` and `b` are in the dependency array.

### 3. The computation function should be a pure function

The computation function passed to `useMemo` should be a pure function and should not have side effects. It should only return a value based on its inputs and should not modify external state.

### 4. Cached values may be discarded

React may discard cached values in certain situations, such as when a component re-renders in development mode. Therefore, do not rely on the persistence of cached values.

### 5. It may be called twice in Strict Mode

In Strict Mode, React may call the computation function twice. This is to help detect unexpected side effects, so the computation function must be a pure function.

## DO

- **Cache expensive computation results**: For values that require a lot of computation, you can use `useMemo` to cache the result and improve performance.

  **Example:**

  ```jsx
  const expensiveResult = useMemo(() => {
    // 进行昂贵的计算
    return computeExpensiveValue(data);
  }, [data]);
  ```

- **Avoid unnecessary re-renders of child components**: Combined with `React.memo`, it can prevent child components from re-rendering when it is not necessary.

  **Example:**

  ```jsx
  const MemoizedChild = React.memo(ChildComponent);

  function ParentComponent({ propA }) {
    const memoizedValue = useMemo(() => computeValue(propA), [propA]);

    return <MemoizedChild value={memoizedValue} />;
  }
  ```

- **Memoize functions**: You can use `useMemo` or `useCallback` to memoize functions and prevent them from being recreated when dependencies have not changed.

  **Example:**

  ```jsx
  const memoizedCallback = useCallback(() => {
    doSomething(a, b);
  }, [a, b]);
  ```

## DONT DO

- **Do not use `useMemo` on every render**: Using `useMemo` unnecessarily may increase code complexity without any obvious performance gain.

- **Do not omit dependencies**: Deliberately omitting dependencies to avoid recomputation is a wrong practice and may lead to unpredictable results.

- **Do not use `useMemo` inside loops or conditional statements**: `useMemo` must be called at the top level of a component and cannot be used inside loops, conditions, or nested functions.

  **Incorrect example:**

  ```jsx
  if (condition) {
    const memoizedValue = useMemo(() => computeValue(a), [a]); // ❌
  }
  ```

- **Do not produce side effects in the computation function**: The computation function should be a pure function and should not modify the component's state or cause side effects.

- **Do not rely on the persistence of cached values**: Cached values may be discarded in certain situations, and you should not assume that they will always exist.

## Summary

`useMemo` is a powerful tool that can help us optimize the performance of React applications. However, abusing `useMemo` may increase code complexity and even introduce bugs. When using `useMemo`, follow these principles:

- **Use only when necessary**: Use `useMemo` only when the computation overhead is high and the dependencies do not change frequently.

- **Ensure dependencies are complete**: All external variables used in the computation function should be included in the dependency array.

- **Keep the computation function pure**: Avoid introducing side effects into the computation function.

- **Understand its purpose**: `useMemo` is a tool for performance optimization, and you should not rely on it to ensure the correctness of a component.

By using `useMemo` appropriately, we can improve application performance while ensuring code readability and maintainability.
