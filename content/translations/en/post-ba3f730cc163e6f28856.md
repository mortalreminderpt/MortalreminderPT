## Purpose

`useEffect` is a Hook provided by React that lets us perform side effects in function components. It helps components synchronize with external systems (such as browser APIs, subscriptions, timers, network requests, etc.). After the component finishes rendering, React executes the function passed to `useEffect` to perform the side effects.

**Example:**

```jsx
import { useEffect } from 'react';

function MyComponent() {
  useEffect(() => {
    // 执行副作用操作，如订阅或数据获取
    return () => {
      // 清理副作用，如取消订阅
    };
  }, [dependencies]);
}
```

In this example, `useEffect` accepts a function that can return a cleanup function. `dependencies` is a dependency array; when the values in it change, `useEffect` re-executes.

## Notes

### 1. Dependency Array

The second argument of `useEffect` is the dependency array, which must include all external variables used in the side effect (props, state, and functions and variables defined inside the component). Omitting dependencies may cause the side effect to fail to update in time, or trigger an infinite loop.

**Example:**

```jsx
useEffect(() => {
  // 使用了 propA 和 stateB
}, [propA, stateB]);
```

### 2. Cleanup Function

If the side effect needs to be cleaned up before the component unmounts or updates, you can perform the cleanup in the function returned by `useEffect`. React calls the cleanup function before the component unmounts or before dependencies change.

**Example:**

```jsx
useEffect(() => {
  const subscription = subscribeToSomething();
  return () => {
    subscription.unsubscribe();
  };
}, []);
```

### 3. Avoid Updating State Directly in Side Effects

When updating state in a side effect, be careful to avoid triggering an infinite loop. Make sure that state updates do not cause the side effect to run repeatedly, unless that is intentional.

**Example:**

```jsx
useEffect(() => {
  setCount(prevCount => prevCount + 1); // 使用函数式更新
}, []);
```

### 4. Do Not Use `useEffect` in Conditional Statements or Loops

`useEffect` must be called at the top level of the component, and cannot be called inside conditional statements, loops, or nested functions. This is one of the rules of React Hooks, ensuring that the order in which Hooks are called is consistent on every render.

**Incorrect example:**

```jsx
if (condition) {
  useEffect(() => {
    // ❌ 不要在条件语句中使用
  }, []);
}
```

### 5. Double Invocation in React Strict Mode

In Strict Mode, React calls the execution function and cleanup function of `useEffect` twice on the initial render. This is to help developers discover problems in side effects. Make sure that the side effect function and the cleanup function are idempotent.

## DO

- **Subscriptions and cleanup**: You can use `useEffect` to subscribe to events or data streams, and unsubscribe in the returned cleanup function.

  **Example:**

  ```jsx
  useEffect(() => {
    const handleResize = () => {
      // 处理窗口大小变化
    };
    window.addEventListener('resize', handleResize);
    return () => {
      window.removeEventListener('resize', handleResize);
    };
  }, []);
  ```

- **Data fetching**: You can perform asynchronous operations in `useEffect`, such as fetching data from a server.

  **Example:**

  ```jsx
  useEffect(() => {
    async function fetchData() {
      const result = await axios.get('/api/data');
      setData(result.data);
    }
    fetchData();
  }, []);
  ```

- **Manipulating the DOM**: In side effects, you can manipulate the DOM directly, but using `useRef` is usually recommended.

  **Example:**

  ```jsx
  useEffect(() => {
    document.title = `您有 ${count} 条新消息`;
  }, [count]);
  ```

## DONT DO

- **Do not perform side effects during rendering**: React requires the rendering process to be a pure function and should not have side effects. Side effects should be placed in `useEffect`.

  **Incorrect example:**

  ```jsx
  function MyComponent() {
    // ❌ 不要在渲染中执行副作用
    fetchData();
    return <div>内容</div>;
  }
  ```

- **Do not ignore the dependency array**: If external variables are used in a side effect but not declared in the dependency array, the side effect may not execute correctly.

  **Incorrect example:**

  ```jsx
  useEffect(() => {
    // 使用了 count，但未在依赖项中声明
    document.title = `您有 ${count} 条新消息`;
  }, []); // ❌ 错误的依赖项
  ```

- **Do not use `useEffect` in conditions or loops**: This violates the rules for using Hooks and will cause rendering errors.

- **Do not directly update dependencies in a side effect**: This may cause an infinite loop.

  **Incorrect example:**

  ```jsx
  useEffect(() => {
    setCount(count + 1); // ❌ 导致无限循环
  }, [count]);
  ```

## Summary

`useEffect` is the key Hook in React for handling side effects, used to perform asynchronous operations, subscriptions, DOM manipulation, etc. after a component renders. When using `useEffect`, pay attention to the following points:

- **Specify the dependency array correctly**: Make sure all external variables used in the side effect are declared in the dependency array.

- **Use a cleanup function**: When the side effect needs to be cleaned up before the component unmounts or updates, return a cleanup function.

- **Avoid causing infinite loops in side effects**: Update state carefully to avoid causing the side effect to run repeatedly.

- **Follow the rules for using Hooks**: Do not use `useEffect` in conditions, loops, or nested functions.

By using `useEffect` appropriately, we can effectively synchronize components with external systems and write efficient, stable React applications.
