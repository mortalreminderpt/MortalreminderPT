## The Concept of Scheduling
Background:
When withdrawing money at a bank, ordinary customers are generally served on a first-come, first-served basis, but VIP customers can be served first;
Suppose a group of people need to use the restroom. They can use a first-come, first-served queuing method, or after discussion, those who take less time can use it first.

Similarly, when there is a pile of tasks to process, but due to limited resources, these things cannot be processed at the same time. This requires determining **some kind of rule** to **decide** the **order** in which these tasks are processed, and this is the problem studied by "scheduling".

## The Three Levels of Scheduling


### High-Level Scheduling

Definition of a job: a specific task

A user submitting a job to the system ≈ a user asking the operating system to start a program (to handle a specific task)

When a user submits a large number of jobs to the system, sometimes memory space is limited, and sometimes it is impossible to put all the jobs submitted by the user into memory. At this point, high-level scheduling, i.e., job scheduling, is needed to decide which programs should be started first.

**High-level scheduling (job scheduling)**: According to certain principles, select a job from the job backup queue in external storage and load it into memory, and create a process for it. **Each job is only loaded in once and loaded out once**. When a job is loaded in, a PCB is established, and the PCB is only revoked when the job is loaded out.

### Low-Level Scheduling

**Low-level scheduling (process scheduling / processor scheduling)**: According to a certain strategy, select a process from the ready queue and allocate the processor to it.

Process scheduling is **the most basic type of scheduling** in an operating system, and process scheduling must be configured in general operating systems. The **frequency** of process scheduling **is very high**, generally once every few tens of milliseconds.

### Medium-Level Scheduling

When memory is insufficient, the data of some processes can be swapped out to external storage. When memory becomes free or the process needs to run, it is loaded back into memory.

The state of a process temporarily swapped out to external storage and waiting is the **suspended state**. The PCBs of suspended processes are organized into a **suspend queue**.

**Medium-level scheduling (memory scheduling)**: According to a certain strategy, decide which process in the suspended state should be loaded back into memory. A process may be swapped out of and into memory multiple times, so **the frequency of medium-level scheduling is higher than that of high-level scheduling**.

## The Suspended State of a Process and the Seven-State Model

The state of a process temporarily swapped out to external storage and waiting is the **suspended state (suspend)**, and the suspended state can be further subdivided into two states: **ready suspended** and **blocked suspended**.

Note the difference between "suspended" and "blocked". Both states mean that the process temporarily cannot obtain CPU service, but in the suspended state the process image has been swapped out to external storage, whereas in the blocked state the process image is still in memory.

Some operating systems divide ready suspended and blocked suspended into two suspend queues, and may even further subdivide blocked suspended processes into multiple queues according to different blocking reasons.

## The Connection and Comparison of the Three Levels of Scheduling

| |Behavior|Scheduling Location|Frequency|Impact on Process State|
|---|---|---|---|---|
|High-level scheduling (job scheduling)|According to certain rules, select a suitable job from the backup queue, load it into memory, and create a process for it|External storage→Memory (job-oriented)|Lowest|None→Created state→Ready state|
|Medium-level scheduling (memory scheduling)|According to certain rules, select a suitable process from the suspend queue and swap its data back into memory|External storage→Memory (process-oriented)|Medium|Suspended state→Ready state (blocked suspended→Blocked state)|
|Low-level scheduling (process scheduling)|According to certain rules, select a process from the ready queue and allocate the processor to it|Memory→CPU|Highest|Ready state→Running state|
