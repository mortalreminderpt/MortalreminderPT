## The Three-State Model of Threads

Switching threads back and forth among various states is called **thread control**. Thread states and transitions are almost the same as process states and transitions; usually only the **ready, running, and blocked states of threads** are of concern, which is the three-state model of threads.

## Thread Organization and Control

Similar to processes, the operating system uses a **Thread Control Block (TCB)** and a **Thread table** to accomplish thread organization and control.

<img src='\images\posts\操作系统-进程-线程控制块.jpg'
  style="
    display: block;
    margin-left: auto;
    margin-right: auto; 
    zoom:50%;" />

Thread control block:
- Thread identifier: TID, similar to PID
- Program counter PC: where the thread is executing (points to the address of the next instruction)
- Other registers: intermediate results of thread execution
- Stack pointer: the stack stores function call information, local variables, etc.
- Thread running state: running/ready/blocked
- Priority: a reference for thread scheduling and resource allocation

Thread table:
A thread table can be set up in each process of the operating system, or a single thread table can be formed from all current threads in the system, organizing the various TCBs and managing them by category; this is called **thread organization**.
